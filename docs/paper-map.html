Research-hub architecture

One companion, four distinct layers

The repository mirrors the manuscript without becoming its source repository. Each layer answers a different reader question and carries a different evidentiary weight.

01

Conceptual layer

Evidence dependency, five challenge functions, three figures, and guided literature paths.

02

Review layer

Search protocol, challenge codebook, aggregate counts, overlap results, and interpretation rules.

03

Discovery layer

A 771-paper cross-survey reference library for broader exploration, not a reviewed denominator.

04

Legacy layer

The previous 50-method catalog and 40-record audit, clearly retained only for provenance.
