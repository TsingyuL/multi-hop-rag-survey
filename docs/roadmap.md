# Roadmap

This roadmap follows the current challenge-centered manuscript. Legacy v1
catalog expansion is no longer the organizing goal of the research hub.

## Submission-alignment priorities

1. Publish the final 208-work canonical evidence map with scope tiers.
2. Publish the 135-Core challenge-relation table with Direct, Secondary, and No
   assignments.
3. Publish reviewer and adjudication provenance sufficient to support the
   manuscript's independent-review wording.
4. Add deterministic regeneration for the challenge-count table, pairwise
   Direct-overlap table, and empirical landscape figure.
5. Tag a release that matches the final manuscript review cutoff, figures,
   author metadata, and quantitative snapshot.

## Hub maintenance

- Keep the [paper-to-hub map](paper_hub.md), README, artifact statement,
  figures, and citation metadata synchronized with each manuscript revision.
- Keep the seven-survey reference workbook explicitly separate from the
  reviewed evidence-map denominator.
- Add editable figure sources or provenance where redistribution permits.
- Preserve the v1 catalog and 40-record audit as a clearly labeled legacy
  layer rather than expanding them as the primary taxonomy.

## Quality bar

- Every public paper record has a canonical identity and persistent primary-source URL.
- Every scope-tier and challenge-relation assignment has a source-grounded rationale.
- Changes to manuscript counts originate in row-level coding and regenerate all
  dependent aggregate outputs.
- Claims about coverage or performance identify the dataset and evaluation setting.
- Public completeness statements distinguish aggregate snapshots from
  row-level reproducibility.
- Published release metadata reflects the final venue record only after it is assigned.
