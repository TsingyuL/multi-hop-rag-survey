\subsection{Boundary Decisions}
Reranking is coded as initial retrieval when it refines the query--candidate ranking. It is coded as evidence integration only when the central problem is joint selection or reader-facing organization of an already acquired set. Adaptive retrieval and self-critique remain follow-up retrieval when they alter the current episode; they become feedback learning only when the result is retained across tasks. General memory and skill systems are included only when the stored object changes retrieval-grounded multi-hop behavior.

\subsection{Record-Level Fields}
For each paper, the artifact records title, year, venue, authors, record type, primary category, secondary category, method tags, task setting, evidence environment, task and dataset description, main contribution, evaluation signals, audit-selection status, verification status, canonical source URL, and coding notes. The record-level table is distributed electronically rather than rendered in full because \CorpusSize{} rows would be unreadable in the article appendix.
