# Manuscript figures

This directory keeps the three current vector figure assets used by the TOIS
manuscript:

- [`fig1.pdf`](fig1.pdf): **Figure 1, evidence-dependency scope** - contrasts
  multi-document retrieval with sequential and branch-and-join evidence
  dependency. This corresponds to the manuscript source asset `figs/2.pdf`.
- [`fig2.pdf`](fig2.pdf): **Figure 2, five-challenge control loop** - separates
  evidence-state control from Evidence Composition and shows adequacy,
  integrity, replanning, and feedback transitions. This corresponds to
  `figs/1.pdf`.
- [`fig3.pdf`](fig3.pdf): **Figure 3, challenge-mechanism landscape** - places
  representative systems and mechanism shifts across the five challenge
  functions and publication years. This corresponds to `figs/4.pdf`.

The normalized repository names follow the figures' order in the manuscript;
the original source filenames do not. Replace the matching repository file in
place when a figure is revised so that public links remain stable.
